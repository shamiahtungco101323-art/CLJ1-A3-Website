# CLJ 1 Block A3 Educational Website

Files:
- index.html — main website
- style.css — design and responsive layout
- script.js — mobile menu and quick-review interaction

How to use:
1. Keep all three files in the same folder.
2. Open index.html in a browser.
3. To publish online, upload the folder to a static hosting service such as GitHub Pages.

Topic:
CLJ 1 — Introduction to the Philippine Criminal Justice System
Focus: The Court Pillar, courts, jurisdiction, court proceedings, and judgments.

Note:
Content was organized from the six CLJ 1 class-material photos provided by the student. It is intended for educational use and should be checked against the teacher's latest instructions and official legal sources before submission.
